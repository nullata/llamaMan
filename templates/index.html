Proxy-Side Sampling Overrides

When enabled, the instance public port stays behind a proxy that forces these sampling values on forwarded requests.

Speculative Decoding

When enabled, runs the model with speculative decoding (--spec-type). Every listed draft type takes a small drafter model that predicts tokens for the target to verify; MTP is the only one where the drafter is optional (it falls back to MTP heads built into the main model). The n-gram / lookup speculative types don't take a drafter model and aren't exposed here; use Extra Args for those.

Advanced

All three fields are optional. Leave a field blank and llamaMan omits the flag entirely so llama-server uses its own default (defaults drift across llama.cpp versions, which is why we don't hard-code them here).

Image Input

When enabled, loads a multimodal projector (--mmproj) so a vision model can accept image inputs. Point it at the model's mmproj GGUF alongside the main weights.
